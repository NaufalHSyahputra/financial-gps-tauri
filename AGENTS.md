# Financial GPS project instructions

- For coding and code review, apply [Ponytail](.agents/skills/ponytail/SKILL.md). Reuse existing project code and make the smallest complete change that preserves behavior, security, and data integrity.
- For UI design, visual review, or polish, apply [Unslop](.agents/skills/unslop/SKILL.md) within the requested scope.
- For routine shell commands with verbose output, use [RTK](.agents/skills/rtk/SKILL.md) when available. Use the original command for exact output or diagnostics that need full context.
- For mobile or Tauri WebView UI review, debugging, or polish, apply [Mobile WebView Review](.agents/skills/mobile-webview-review/SKILL.md) alongside [Unslop](.agents/skills/unslop/SKILL.md) and [Web Design Guidelines](.agents/skills/web-design-guidelines/SKILL.md).
- For local browser testing, use [Webapp Testing](.agents/skills/webapp-testing/SKILL.md). Use [Playwright CLI](.agents/skills/playwright-cli/SKILL.md) for interactive browser inspection through `npx --no-install playwright cli`.
